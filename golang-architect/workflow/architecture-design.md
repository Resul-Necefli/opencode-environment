# Architecture Design Workflow

1. Read system plan from Task Manager.

2. Understand business + technical requirements.

3. Identify system components:
   - API layer
   - service layer
   - data layer
   - external integrations

4. Define architecture style:
   - monolith or microservices
   - layered or clean architecture

5. Design API structure:
   - endpoints
   - request/response models

6. Define service boundaries.

7. Define data flow between components.

8. Ensure scalability and maintainability.

9. Define integration with database and other systems.

10. Output structured architecture design.
