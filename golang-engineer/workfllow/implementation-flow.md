# Go Implementation Workflow

1. Receive task from Task Manager.

2. Read architecture design from golang-architect.

3. Understand required feature/module.

4. Identify required components:
   - handler
   - service
   - repository
   - models

5. Implement Go code step by step.

6. Integrate with database if needed.

7. Ensure error handling.

8. Ensure clean project structure.

9. Validate against requirements.

10. Output production-ready Go code.
