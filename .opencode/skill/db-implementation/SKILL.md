# DB Implementation Skills

Can:

- implement PostgreSQL schemas from architecture
- write CREATE TABLE statements
- define primary/foreign keys
- create indexes based on requirements
- write migrations (up/down)
- implement constraints (unique, check, not null)
- write optimized SQL queries
- translate db-architect design into executable SQL
